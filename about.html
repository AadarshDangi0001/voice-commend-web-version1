About Voice Commands

This voice-controlled system allows you to navigate and interact with the website using voice commands. Below are the available commands:

🔹 Navigation Commands

  • Go to home page / Open home page - Navigates to the home page.
  • Go to about page / Open about page - Opens the about page.
  • Go to contact page / Open contact page - Opens the contact page.

🔹 Scrolling Commands

  • Scroll down - Scrolls the page downward.
  • Scroll up - Scrolls the page upward.
  • Scroll top - Moves to the top of the page.
  • Scroll bottom - Moves to the bottom of the page.

🔹 Sound Control

  • Sound on / आवाज़ चालू - Enables voice feedback.
  • Sound off / आवाज़ बंद - Disables voice feedback.

🔹 Language Switching

  • Hindi / हिंदी - Switches to Hindi language.
  • English / इंग्लिश - Switches to English language.

🔹 Stop Voice Recognition

  • Stop / बंद करो - Stops voice recognition.

More features and commands will be added soon!
